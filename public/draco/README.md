# Draco decoder

`draco_decoder.js`, `draco_decoder.wasm` and `draco_wasm_wrapper.js` are Google's
[Draco](https://github.com/google/draco) glTF decoder, copied unchanged from
`three/examples/jsm/libs/draco/gltf`. They're self-hosted so loading the 3D models
never calls a third-party CDN.
